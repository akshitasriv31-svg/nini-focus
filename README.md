
# 🧠 FocusForge

FocusForge is an ADHD- and AuDHD-friendly productivity app designed to help users organise tasks, reduce overwhelm, and stay focused.

## Features

- ✅ Add and delete tasks
- ✅ Save tasks using Local Storage
- ✅ Mark tasks as completed
- 🚧 AI-powered task prioritisation (Coming Soon)
- 🚧 Brain Dump mode
- 🚧 Focus Mode
- 🚧 Reminder system
- 🚧 Photo verification for completed tasks

## Built With

- HTML
- CSS
- JavaScript

## Future Goals

- Smart AI assistant  
- Energy-based task recommendations
- Daily productivity analytics
- Mobile app version
